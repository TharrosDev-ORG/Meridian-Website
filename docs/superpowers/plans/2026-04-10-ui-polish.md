> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Apply surgical mobile layout fixes and desktop interaction polish to the Meridian Website across index.html, events.html, team.html, nav.css, and site.js.

**Architecture:** All page-specific styles live in inline `<style>` blocks per CLAUDE.md — no new CSS files. JS changes go into the existing inline `<script>` blocks and `site.js`. **Tech Stack:** Vanilla HTML/CSS/JS, csso-cli + terser (npm build), no framework.

  In the same inline `<script>`, after the hero ghost parallax IIFE (which ends with `}, { passive: true });`), add a new IIFE:

  ```js
  // ── Register ghost parallax ──
  (function() {
    var ghost = document.querySelector('.register-ghost');
    if (!ghost) return;
    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;
    window.addEventListener('scroll', function() {
      ghost.style.transform = 'translateX(-50%) translateY(' + (window.scrollY * 0.08) + 'px)';
    }, { passive: true });
  }());
  ```
