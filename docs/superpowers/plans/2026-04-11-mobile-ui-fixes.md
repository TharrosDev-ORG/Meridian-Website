## Task 1: Fix index.html mobile CSS

**Files:**
- Modify: `index.html` lines 888, 892, 1034–1035, and inside `@media (max-width: 700px)` block (~line 1062)

### 1a. Fix not-list hover reflow (lines 888, 892)

- [ ] **Open** `index.html`. Find line 888 — the `.not-list li` rule. The `transition` property currently includes `padding-left 0.3s` which causes layout reflow. Replace it with `transform 0.3s`:

**Find (line 888):**
```css
      transition: color 0.25s, padding-left 0.3s, border-bottom-color 0.25s; cursor: default;
```
**Replace with:**
```css
      transition: color 0.25s, transform 0.3s, border-bottom-color 0.25s; cursor: default;
```

- [ ] **Find line 892** — the `.not-list li:hover` rule. Replace `padding-left` with `transform`:

**Find (line 892):**
```css
    .not-list li:hover { color: var(--ink); padding-left: 8px; }
```
**Replace with:**
```css
    .not-list li:hover { color: var(--ink); transform: translateX(8px); }
```

### 1b. Fix footer-col hover reflow (lines 1034–1035)

- [ ] **Find line 1034** — the `.footer-col a` rule. Replace `padding-left 0.2s` in transition with `transform 0.2s`:

**Find (line 1034):**
```css
    .footer-col a { display: block; font-family: var(--serif); font-size: 15px; color: var(--ink-75); text-decoration: none; margin-bottom: 8px; transition: color 0.2s, padding-left 0.2s; }
```
**Replace with:**
```css
    .footer-col a { display: block; font-family: var(--serif); font-size: 15px; color: var(--ink-75); text-decoration: none; margin-bottom: 8px; transition: color 0.2s, transform 0.2s; }
```

- [ ] **Find line 1035** — the `.footer-col a:hover` rule. Replace `padding-left` with `transform`:

**Find (line 1035):**
```css
    .footer-col a:hover { color: var(--ink); padding-left: 4px; }
```
**Replace with:**
```css
    .footer-col a:hover { color: var(--ink); transform: translateX(4px); }
```
